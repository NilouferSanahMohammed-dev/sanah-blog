Drop your own photos in here.

The page looks for these filenames by default (see the `data-placeholder`
text in `index.html` for exactly which ones), but you can rename anything —
just update the matching `<div class="photo-slot">` in `index.html` to use
a real `<img src="images/yourfile.jpg">` instead of the placeholder div.

Suggested starting set:
- hero.jpg — the photo next to your name at the top
- about.jpg — a photo for the about section
- gallery-1.jpg through gallery-6.jpg — your gallery grid

Any image size works, but square-ish photos (roughly 1:1) will sit
best inside the polaroid frames without cropping oddly.
